Current Research Directions

These projects explore how machines can discover interpretable rules and structures from data and use them for reasoning and prediction. The research combines data-driven learning with symbolic representations and domain knowledge, spanning inductive logic programming, neuro-symbolic reasoning, and scientific discovery.

Inductive Logic Programming and Rule Learning

  • This project aims to develop methods for learning logical rules from structured data and perceptual observations, with a focus on differentiable inductive logic programming, predicate invention, and hierarchical rule composition. Incremental learning of temporal first-order rules extends these methods to relationships that evolve over time.
  • Listed Problems: Answer Set Programming, Symbol Grounding, Predicate Invention, Object Representations, etc.

Neuro-Symbolic Reasoning with Large Language Models

  • This direction connects language understanding with explicit entities, relations, and logical rules to support structured and interpretable reasoning. Key questions include how symbolic constraints can guide inference and how integrating language models with symbolic methods can improve the consistency of predictions.
  • Listed Problems: Benchmark Making, LLM Post-training, CoT Development, RAG Building

Symbolic Scientific Discovery and Time-Series Modeling

This direction explores the discovery of explicit mathematical relationships from scientific data. Incorporating physical knowledge and scaling constraints into symbolic learning supports interpretable models of complex processes, including ocean heat transport. Related work investigates representations for non-stationary time-series forecasting.

Previous Research Directions

Knowledge Graph Completion and Reasoning

This direction integrates logical rules with neural reasoning over incomplete knowledge graphs. Topics include incorporating Horn-rule priors into graph neural networks, preserving relation order during multi-hop inference, and adaptively selecting relevant entities and paths to improve reasoning efficiency and interpretability.
